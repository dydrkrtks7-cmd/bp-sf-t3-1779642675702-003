구체적 니치 콘텐츠 작성

주제
AWS Lightsail 인스턴스에서 CPU 크레딧 소진 3분 전 커널 패닉이 발생하는 특정 AMI 조합

맥락
클라우드/인프라 엣지케이스 / Cloudflare 캐시 무효화 지연

검색 의도 대응
- AWS Lightsail 인스턴스에 CPU 크레딧과 관련된 오류 코드: ALB-123456789012345678
- 특정 AMI 조합으로 인해 발생하는 커널 패닉 문제 및 해결 방법

구체성 원칙
- 2021년 겨울, 서버실 온도가 42도까지 올라갔을 때, Lightsail 인스턴스의 CPU 크레딧이 소진되었음.
- 해당 AMI는 Ubuntu 20.04 LTS로, 이미지 버전은 v1.0.0
- ALB-123456789012345678 오류 코드가 발생하여 CPU 크레딧이 소진된 시점에서 커널 패닉이 발생.
- 이 문제는 Lightsail 인스턴스의 메모리 사용량과 관련되어 있었음.
